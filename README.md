## Installation rapide

### Option 1 : Script automatique (recommandé)

**macOS / Linux :**
```bash
chmod +x install.sh
./install.sh
```

**Windows (PowerShell) :**
```powershell
.\install.ps1
```

### Option 2 : Installation manuelle

1. Copiez le contenu du dossier `skills/` vers `~/.claude/skills/`
2. Redémarrez Claude Code
3. Tapez `/atoox` pour vérifier
